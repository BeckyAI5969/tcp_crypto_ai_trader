# Sprint 27 — TCP Strategy Lab Platform v1.0

Extract this ZIP into the project root, then run:

```powershell
py -B tools\initialize_strategy_lab.py
```

Open:

```text
strategy_lab/dashboard/strategy_dashboard.html
```

The initializer creates the full organized structure, registers Research Original,
v0.1.0, v0.1.1 and planned v0.1.2, imports available metrics, creates strategy
history and generates the dashboard.
