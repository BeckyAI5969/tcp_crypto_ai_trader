# Strategy Lab v0.1.1

Place `strategy_lab_v0_1_1.py` in the project's `research/` folder.

Run once from the project root:

```powershell
py -B research\strategy_lab_v0_1_1.py
```

Outputs are created under:

```text
reports/strategy_lab/v0.1.1/
```

This version reproduces the original research strategy with fixed 4% TP,
-2% SL, EMA20 profit exit, fixed 2,500 notional, and zero fees/slippage for
benchmark parity.
